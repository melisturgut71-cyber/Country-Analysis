# 🌍 World Countries Socio-Economic Analysis

## 📌 Proje Hakkında
Bu proje, dünya ülkelerinin sosyo-ekonomik verilerini (GDP, Nüfus, Okuryazarlık, Bebek Ölüm Oranları vb.) analiz ederek ülkeleri gelişmişlik düzeylerine göre segmentlere ayırmayı amaçlayan bir Veri Bilimi çalışmasıdır.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Python 3.x
* **Kütüphaneler:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn (KMeans Clustering)

## 📊 Yapılan Analizler
1.  **Veri Temizliği:** Eksik verilerin bölgesel medyan değerlerle doldurulması.
2.  **Keşifçi Veri Analizi (EDA):**
    * GDP ve Okuryazarlık arasındaki korelasyon analizi.
    * Bölgelere göre dağılımlar.
3.  **Kümeleme (Clustering):** K-Means algoritması ile ülkelerin gelişmişlik seviyelerine göre 3 farklı kümeye ayrılması.
4.  **Sıralama Analizleri:** Nüfus, GDP ve Nüfus yoğunluğuna göre lider ülkelerin belirlenmesi.

## 📈 Örnek Bulgular
* Kişi başı milli gelir (GDP) ile telefon sahipliği arasında çok güçlü bir pozitif korelasyon gözlemlendi.
* Eğitim seviyesi (Okuryazarlık) arttıkça bebek ölüm oranlarının ciddi şekilde düştüğü tespit edildi.
